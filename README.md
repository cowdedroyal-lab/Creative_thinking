## 问题

这是课程复习资料，各部分要回答的问题：

- 讲义笔记：每一讲讲了哪些概念、方法和案例，考前怎么按顺序过一遍。
- 章节习题：每章的思考题、练习题和案例分析题怎么答，答案落在哪个知识点上。
- TRIZ 专题：40 个发明原理、矛盾矩阵、物理矛盾的分离原理分别在什么问题上用。
- 导航工具：遇到一个具体问题时，怎么从问题类型、场景或关键词快速定位到该用的方法和讲次。

## 方案

- 按讲整理：第 1 到 9 讲各一个 Markdown 文件，从创新概念与素质，到发散与收敛思维、创新技法，再到 TRIZ 的理想解、进化法则、矛盾解决。
- 按章配习题：`第N章问题.md` 与讲次一一对应，每题含解题思路和参考答案。
- 专题：`TRIZ 40个发明原理详解.md` 与 `从研究生自身角度谈想象力的培养方法.md`。
- 导航：`导航工具/TRIZ工具速查表.md` 汇总 5 个 WHY、小人法、九屏幕法、金鱼法和选择决策树；`导航工具/快速检索索引.md` 提供按问题类型、应用场景、关键词、学习目标、难度的检索。

```

```

### 学习建议

1. **循序渐进**：按课程顺序阅读讲义，每讲完成后做对应章节习题
2. **理论结合实践**：尝试将所学方法应用于实际问题
3. **TRIZ 重点突破**：第 7-9 讲与 `TRIZ 40个发明原理详解.md` 建议搭配学习
4. **案例分析**：讲义中包含大量实例，注意理解其背后的思维逻辑

### 核心知识点速览

- **创新能力公式**：创新能力 = K ×（创造性人格 + 创造性思维 + 创新方法）× 知识量²
- **TRIZ 理想度**：理想度 = Σ有用功能 /（Σ有害作用 + 成本）
- **技术系统进化 S 曲线**：婴儿期 → 成长期 → 成熟期 → 衰退期
- **八大进化法则**：完备性、能量传递、协调性、提高理想度、动态性、子系统不均衡进化、向微观级进化、向超系统跃迁

## 📚 课程简介

本课程旨在培养创新型人才，系统讲授创新思维的特征、规律与方法，帮助学习者：

- 树立正确的创新观，理解创新的本质与价值
- 掌握发散思维、收敛思维、逻辑思维等多种思维方式
- 学习头脑风暴法、模块化、延伸法、移植法等创新技法
- 深入理解 TRIZ（发明问题解决理论）的核心工具与方法

**课程目标**：培养学生的创新思维能力和悟性，训练发明创造技能，引导大胆创新。

## 📝 习题解析编写指南

为提升学习效果，建议为每章习题配套独立的解析文档（如`第X章问题解析.md`），按以下结构组织内容：

### 解析文档结构

- **【题目回顾】** 简要重述或概括题目内容
- **【知识点定位】** 标注对应章节与核心概念（如"第3讲·发散思维""TRIZ 40原理-分割原理"）
- **【参考答案】** 条理清晰地呈现答案要点，推荐使用列表或步骤式表达
- **【思路解析】** 阐述解题逻辑与方法应用，指出常见误区与易错点
- **【拓展思考】**（可选）提供 1-2 个同类型变式题目，引导深度思考

### 使用建议

- 教师可作为教学参考，灵活调整答案深度与拓展难度
- 自学者应**独立完成习题后**再查看解析，避免依赖答案削弱思维训练效果
- 鼓励结合讲义案例，尝试用多种创新方法求解同一问题
